## Featured Projects

> A selection of production systems and notable work.

**ETSolar Store Website** · *Full-Stack · Next.js · MongoDB · AI*

Commercial solar product storefront with a public catalog, multi-step inquiry flows, and a protected admin CMS covering products, brands, surveys, blog content, role-based permissions, and Cloudinary media management. Built solo end-to-end.

---

**ETech / ETSolar Mobile App** · *React Native · ASP.NET Core · Oracle Database*

Cross-platform customer-service app for ETSolar. Built the Expo React Native frontend and extended a legacy ASP.NET Core API to support OTP auth, complaints, inquiries, and account management — deployed to Google Play Store with IIS/SSL backend.

---

**ETSolar WhatsApp CRM & AI Sales Assistant** · *FastAPI · Next.js · OpenAI · WhatsApp Cloud API*

AI-powered WhatsApp CRM that routes customer messages, generates contextual sales replies, and manages inquiry workflows through a Next.js admin dashboard with MongoDB-backed data storage.

---

**ETSolar AI Social Media Automation** · *n8n · OpenAI · GPT-Image · Google Sheets*

Production n8n automation stack handling multi-platform content generation (Facebook, Instagram, LinkedIn, X, Reddit, TikTok), AI image generation via GPT-Image, Slack approval pipelines, and 24/7 deployment on client-hosted infrastructure.

---

**CutConnect** · *Next.js · Node.js · PostgreSQL · Stripe*

Denmark-market barber booking platform. Led frontend delivery for client, barber, shop owner, and admin workflows in a 3-member team. Connected with REST APIs for bookings, subscriptions, reviews, Stripe payments, and Google Maps.

---

**SkillSwap** · *React · NestJS · FastAPI · Docker · Socket.IO*

Full-stack freelance marketplace built with microservices architecture — API gateway, separate auth/project/messaging/payment services, real-time Socket.IO, voice search via FastAPI, Stripe escrow, and full Docker Compose containerization.

---

**Visure** · *Next.js · FastAPI · MediaPipe · RAG · Computer Vision*

Final year project — AI-assisted fashion platform with body measurement analysis, size recommendations, virtual try-on, and intelligent shopping assistant powered by RAG workflows, MediaPipe, and Groq API.

---

**Disaster-Aware Emergency Recommendation System** · *Python · FAISS · RAG · Google Gemini · LoRA*

AI disaster recommendation engine using FAISS vector search over 50K records, geospatial Haversine ranking, weighted re-ranking, RAG with Gemini, and a LoRA fine-tuning pipeline on GPT-Neo via Hugging Face.
